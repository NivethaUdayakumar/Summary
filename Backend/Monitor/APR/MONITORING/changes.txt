APR monitor pre-submit validation changes

1. Added check_valid_job() in APR_STATUS_ACTION.py.
- Returns ERR002 when the KPI report file does not exist.
- Returns ERR001 when get_timing_report_paths() is blank or None.
- Prevents invalid monitor items from being submitted for extraction.

2. Updated perform_status_action() in APR_STATUS_ACTION.py.
- Runs check_valid_job() before queueing a batch item.
- Removes invalid items from the pending queue.
- Marks invalid items immediately with the correct status and comment.
- Removes matching force-extract requests so the same invalid run is not retried every cycle.

3. Added persisted validation error handling in APR_STATUS_ACTION.py.
- Stores validation_failed:ERR001 or validation_failed:ERR002 in Last_extract_result.
- Keeps Force_extract at 0 for rejected items.

4. Updated compute_status() in APR_ITEM_STATUS.py.
- Reuses the persisted validation result when the log file has not changed.
- Keeps ERR001 runs in Extraction Failed.
- Keeps ERR002 runs in Job Failed.

5. Updated apply_kpi_status() in APR_UPDATE_TRACKER.py.
- Reads the persisted validation error from state_entry.
- Preserves ERR001 or ERR002 in Comments for pre-submit failures.
- Keeps Promote as no for those failures.
